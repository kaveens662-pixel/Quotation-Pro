🇬🇧 About the Project

Question Pro is an Android application project designed to simplify the process of creating, calculating, organizing, and managing quotations.

The goal is to provide a clean, modern, and user-friendly experience for individuals and small businesses that need an easier way to manage quotation-related tasks.

🚀 Getting Started

Requirements

- Android Studio
- Android SDK compatible with the project
- JDK version compatible with the configured Android Gradle Plugin
- Internet connection for downloading dependencies

Build the Project

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Allow Gradle synchronization to complete.
4. Build and run the app on an emulator or Android device.

Build an APK with GitHub Actions

This repository can use GitHub Actions to build a debug APK in the cloud.

1. Open the Actions tab.
2. Select the Android APK build workflow.
3. Run the workflow, if manual execution is enabled.
4. Wait for the workflow to finish successfully.
5. Download the APK ZIP file from Artifacts, if the artifact was uploaded successfully.

«A downloadable APK is not guaranteed until the workflow completes successfully.»
